# 非遗跨境展演知识边界

本项目用于整理非遗跨境展演知识边界领域中的事件名称、交换字段与脱敏样例，并提供一套可运行的知识边界服务，方便业务、运营和研发人员在同一套术语下讨论后续服务。资料只包含领域约定与虚构样例，不包含真实个人信息、生产连接或外部账号。

## 服务规则

1. **知识单元**：技艺（TECHNIQUE）、故事（STORY）、影像（MEDIA）、译文（TRANSLATION）、互动（INTERACTION）五类，分别注明来源共同体、可公开地域、受众年龄、署名、录制、商业用途与到期日。
2. **联合许可**：节目引用任意单元，必须同时满足全部许可——地域取交集、年龄取最高下限、录制与商业用途取逻辑与、到期日取最早、署名全部保留。
3. **改义失效**：翻译或剪辑改变含义后，原确认不再沿用，单元回到待复核状态；源头内容改义会波及直接衍生单元（如译文）。
4. **离线材料包**：签发时记录每个单元的版本与内容哈希（可验证版本），并带自动失效信息（许可到期日与包有效期的较早者）；篡改、过期、单元版本漂移或许可撤回都会使校验失败。
5. **临场问答边界**：讲解员只能引用节目已获准的单元作答，且场景（地域/年龄/录制/商业）仍在联合许可范围内，否则拒答并留痕。
6. **许可撤回**：不否定已依法完成的场次，但后续下载与复用必须停止；争议与替代素材持续留痕。
7. **溯源**：传承人可查到某段知识在哪座城市、哪次活动、哪种媒介中出现过（`unitReport` / `appearancesOf`）。

所有状态变化写入带链式哈希的追加式事件账本（`src/ledger.js`），`verifyLedger()` 可发现对历史记录的篡改。

## 目录

- `src/heritage_exchange_boundary.js`：事件种类与最小字段校验。
- `src/units.js`：知识单元分类、许可字段校验、联合许可与场景覆盖检查。
- `src/ledger.js`：防篡改事件账本。
- `src/service.js`：知识边界服务（登记/确认/修订/节目/材料包/问答/撤回/溯源）。
- `data/sample.json`：用于核对资料格式的虚构事件。
- `data/tour_units.sample.json`：虚构的巡演知识单元样例（面塑、茶艺、民族纹样、译文）。
- `examples/demo.js`：从登记到撤回留痕的完整演示。
- `tests/`：保证样例与领域约定、服务规则保持一致。

## 本地核对

```bash
npm test          # 运行全部测试
npm run demo      # 运行完整流程演示
```
